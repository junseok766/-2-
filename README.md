# 수출하는 산업은 일자리를 얼마나 만들까? — 2023 산업연관표 분석 웹앱
HTML/CSS/JS만 사용하는 정적 웹앱(빌드 불필요). GitHub Pages로 바로 배포할 수 있습니다.

## 메뉴 구성 (4개 그룹)
- **요약**: 핵심 지표 4개, 주요 발견, 사용 순서
- **분석**: 수출률 × 일자리(산점도·상관계수) / 대외거래 / 노동구조
- **시뮬레이션**: 소비·투자·수출 비교(대분류 계수) / 380부문 수요충격(예시 버튼 4개)
- **자료**: 기본부문 원자료 탐색(12개 시트) / 탐구 질문·한계
- 모든 차트에 "읽는 법·해석" 문구가 있고(선택값에 따라 자동 변경), 차트 우상단 `PNG 저장` 버튼과 CSV 다운로드를 제공합니다.
- **발표 모드**: 전체화면 + 큰 글자. ← → 키로 화면 이동, Esc로 종료합니다.

## 파일
- `index.html`, `style.css`, `app.js`(차트), `explorer.js`(탐색·시뮬레이션), `data.js`(보도자료 요약표)
- `data/sheet0~11.json`, `data/meta.json`: `투입산출표_생산자가격_기본부문.xlsx`을 변환한 데이터(약 9MB)
- 차트 라이브러리 Chart.js 4.4.1(cdnjs)

## 로컬 실행
`fetch`를 쓰므로 파일을 더블클릭하지 말고 서버로 여세요: `python -m http.server 8000` → http://localhost:8000

## GitHub Pages 배포
1. 이 폴더 전체(`data/` 포함)를 저장소 루트에 업로드
2. Settings → Pages → Branch `main` / `(root)` 저장

## 계산 방법
수요충격 시뮬레이터: 생산유발액 = 생산유발계수표 × 최종수요 증가액, 수입·부가가치도 각 유발계수표를 같은 방식으로 곱합니다. 부가가치유발 + 수입유발 = 1(국산 최종수요 기준)을 불러올 때 자동 검증합니다.
